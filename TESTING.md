# Проверки

22 октября 2026 года. Локально пройдено 20 тестов на Python 3.12.

Прайсы, сопоставление колонок, произвольная схема, обязательные поля, числа, разделители, заголовки, дубли, происхождение строк, CSV-экспорт и пограничные значения.

Команда: `python -m unittest discover -s tests -v`.

Основной сценарий интерфейса проверен в Chrome на 1440×1000 и 390×844. Необработанных ошибок JavaScript в пройденных сценариях не зафиксировано. Снимки находятся в `screenshots/`.

Подготовлена матрица GitHub Actions для Python 3.10 и 3.12; сам workflow в GitHub пока не запускался. Дополнительно проверена совместимость синтаксиса с Python 3.10.
